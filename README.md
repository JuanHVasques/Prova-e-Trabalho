## Primeira Parte

1- Como a imagem original mudou após a aplicação de cada filtro?
R: Media = A imagem ficou mais desfocada que a Original parecendo que a camera ficou sem lente de oculos
Mediana = A imagem ficou mais borrada que a Original
Sobel = parece que a imagem ficou preta e tentou fazer a figura com linhas brancas realçando o objeto

2- Qual filtro foi mais eficaz para suavizar a imagem?
R: O filtro para suavizar a imagem é Media visto que desfocou muito a imagem fazendo que mudasse absurdamente em relação ao origianal

3- E qual foi mais eficaz para destacar as bordas?
R: O filtro para destacar as bordas foi o Sobel, pois ele realçou as linhas do objeto em um fundo preto

4- Quais situações podem exigir o uso de cada tipo de filtro em um projeto real?
R: As situações que podem ser usadas são:
Media: Usados mais fundos de imagens para destacar o objeto que é o foco, muito usado no instagram por exemplo
Mediana: Usado para tratar pixels defeituosos nas imagens, muito usado nos raio-x e tomografias no ramo medico
Sobel: Usado para destacar as bordas do objeto deixando mais simples o que é o objeto, muito usado para ler placas de carro ou para carros autônomos reconhecer faixas
